# React TypeScript Learning Hub

An interactive learning platform designed to demonstrate core React and TypeScript concepts through explanations, practical code examples, live demos, and quizzes.

The project provides a structured environment for exploring modern React development while practicing TypeScript in real-world component examples.

## Features

- Interactive lessons covering React and TypeScript concepts
- Practical code examples for each topic
- Live component demonstrations
- Quiz sections for reinforcing learned concepts
- Responsive user interface
- Dark and light theme support
- Custom React hooks
- Component-based architecture

## Technologies

- React 18
- TypeScript
- Vite
- HTML5
- CSS3

## Getting Started

### Prerequisites

Make sure you have Node.js and npm installed on your system.

### Installation

1. Clone the repository:

```bash
git clone https://github.com/X1F-062/react-typescript-learning-hub.git
```

2. Navigate to the project directory:

```bash
cd react-typescript-learning-hub
```

3. Install the dependencies:

```bash
npm install
```

4. Start the development server:

```bash
npm run dev
```

5. Open the local URL displayed in the terminal in your browser.
